# pytest-ditto brand assets

The Ditto frame combines two identical marks with snapshot corners. The second
mark and the second t in ditto share an accent color.

| Element | Light | Dark |
| --- | --- | --- |
| Frame, first mark, and main ditto lettering | Violet `#7143DB` | Lavender `#C6ADFF` |
| Second mark and second t | Teal `#008F82` | Mint `#64D6BA` |
| pytest- lettering | Ink `#242035` | Off-white `#F7F3FF` |
| Background | White `#FFFFFF` | Midnight `#241E38` |

Use `logo-light.svg` and `logo-dark.svg` for horizontal wordmarks on a matching
light or dark surface. The `logo-on-background-*` files include their background.
Use the `icon-*` files for transparent standalone marks and the `tile-*` files
for square icons with a rounded background. PNG versions are also supplied.

The wordmarks use outlined Inter Regular lettering at its display optical size.
All production SVGs contain vector paths and shapes, so they render without
installed fonts. Preserve the lettering, two-color pairing, and spacing when
resizing. The original [Inter font](https://github.com/rsms/inter) uses the
[SIL Open Font License](FONT-LICENSE.txt).

`favicon.svg` adapts to the browser's light or dark preference. The 16px and 32px
PNG favicons use the light tile and are available as static alternatives.
